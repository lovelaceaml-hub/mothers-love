# Lane B2: Public display arrival overflow

## Scope

Terra high fallback, limited to the public display bridge and its rollback-only synthetic SQL fixture.

## Correction

- The bridge reads at most 1,001 eligible arrivals after a valid cursor.
- When the 1,001st arrival exists, it returns the current snapshot with `sync: reset`, empty arrivals, and the latest cursor. This prevents a display from advancing past arrivals it never received.
- The synthetic fixture creates 1,001 eligible publication events for a currently visible featured recognition, verifies the bounded reset, then verifies that one new event produces a normal one-arrival delta from the reset cursor.
