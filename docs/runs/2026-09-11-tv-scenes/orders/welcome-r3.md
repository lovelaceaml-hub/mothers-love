3. Spin. In welcome.css add a steady-state spin that never touches the text: a rotating ring on `#tv .scene[data-scene="1"] .orb-slot::after` (inset -6px, border-radius 50 percent, a conic-gradient of transparent, #fff9 and the tint `var(--tint)` at low alpha, `animation: welcomeRingSpin 9s linear infinite`, per-slot `animation-delay` from the existing `--delay` variable if present, else set `--delay` per actor in mountWelcome), and speed the existing sheen sweep for this scene only (`#tv .scene[data-scene="1"] .orb-sheen:after { animation-duration: 7s }`).
