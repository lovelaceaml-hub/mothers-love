### Plan 24 P0: the Linux CI readiness failure (world branch)

The `Cinematic world preview review` workflow exists only on the world branch, so its fix is a pull request into `feat/world-cinematic`: [#16](https://github.com/lovelaceaml-hub/mothers-love/pull/16), branch `fix/world-review-localhost`.

- **Root cause.** The workflow runs `next dev` and the review opens `http://127.0.0.1:3000`. Next.js 16 blocks cross-origin requests to dev resources, and the dev server calls itself `localhost`, so it refuses the `/_next/hmr` socket from `127.0.0.1`. Without that socket, the page stays on "Opening your world..." and never sets `data-ready`.
- **Reproduced** with CI's setup (xvfb, SwiftShader, 1920 x 1080, reduced motion) on 7e1e8bd. It gave the same 60 second `waitForFunction` timeout and the same socket errors as the stored baseline.
- **Fix:** the review opens `localhost` instead. With only that change, all six checks pass with no errors.
- **Not changed:** no timeout was raised and no error was suppressed.
