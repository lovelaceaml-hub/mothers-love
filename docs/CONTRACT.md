## Stable cross-lane interfaces
Foundation owns src/lib/contracts.ts, src/lib/catalog.ts, src/lib/client-api.ts and src/lib/auth-client.ts until frozen. Every interface uses camelCase JSON. No client imports server modules. Shared types:
- Expression {id:number, phrase:string, principle:string, color:string, example?:string}.
- RecognitionInput {submittedName:string,recipient:string,message:string,expressionIds:number[],requestKey:string}. EditableRecognitionFields contains only submittedName,recipient,message,expressionIds; requestKey is immutable.
- Recognition {id:string,recipient:string,message:string,expressionIds:number[],createdAt:string,firstPublishedAt:string|null,expiresAt:string,version:number,status:'held'|'published'|'hidden'|'invalid',featured:boolean}.
- AdminRecognition extends Recognition with submittedName:string, reason:string|null.
- Aggregate {periodStart:string,periodEnd:string,recognitions:number,expressionCounts:number[],expressionTotal:number,revision:number}; counts array exactly9 canonical positions.
- DisplaySettings {version:number,mode:'normal'|'quiet'|'neutral',motion:'calm'|'standard'|'lively'|'still',pauseArrivals:boolean,pauseRotation:boolean,collectionOpen:boolean,lowActivityMinutes:number,readingSeconds:number,maxBubbles:number,showTrails:boolean,showConstellations:boolean}.
- DisplaySnapshot {serverTime:string,revision:number,recognitions:Recognition[],aggregate:Aggregate,settings:DisplaySettings,submissionUrl:string,cursor:string,sync:'reset'|'delta',arrivals:{eventId:string,recognitionId:string,publishedAt:string}[]}. Recognition status always published, valid, unexpired in display snapshot; never submittedName or private reason. Snapshot without after cursor or with stale cursor returns sync reset and arrivals empty; recent valid cursor returns delta arrivals but always a complete authoritative recognition set. Cursor is opaque bounded server event position, not a personal archive. Client resets cursor on reconnect and does not treat an existing pool as new.
- AdminSession {id:string,role:'owner'|'moderator',needsMfa:boolean}. Owner email is a protected runtime provisioning input, never fixture or public docs.
- ApiError {error:string,code:string}; client api<T>(path,options?) fetches JSON, throws Error with code/status, handles bearer session where supplied. Error bodies have no request content.

## Integration safety clarification

This is a live health precondition, not an elapsed monitoring gate.
