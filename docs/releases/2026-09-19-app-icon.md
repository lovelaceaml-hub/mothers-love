# Butterfly-heart app icon

## Authorization and scope
Anthony selected the top-middle butterfly icon with the added heart, then approved the standalone rose-gold butterfly-and-heart artwork. He requested applying that exact artwork as the app symbol only. No screen redesign, TV changes, recognition changes, database access, or authentication changes are included.

Production baseline: b7d92a07f20ee27351d8af254b3f5e36f52f40c8 on codex/mothers-love. Unreleased TV branches are not included.

Source artwork: rose_gold_butterfly_heart_emblem.png from the design conversation. The repository contains a compact 512 by 512 AVIF derivative with the same framing and composition, not a redraw. The original full-resolution PNG remains in the conversation.

## Implementation
scripts/generate-app-icons.mjs runs before npm run dev and npm run build. It uses sharp, already installed by Next.js, to generate opaque static PNGs at 16, 32, 48, 64, 180, 192 and 512 pixels, an Apple touch-icon fallback, and a real 16/32/48-pixel ICO. No runtime image conversion, new package, external asset host, or service worker is introduced.

Root metadata declares versioned browser and Apple icons. src/app/manifest.ts declares the 192 and 512 PNGs for installed apps. Existing page title, description, light theme, theme color, providers and rendering are preserved. Only the install metadata supplies the standard standalone launch mode; page components and app behavior are otherwise unchanged.

## Verification
The generator was executed locally. All seven PNG files decoded at their expected dimensions and were RGB/opaque. The ICO contained exactly 16, 32 and 48-pixel entries. The Apple fallback matched the 180-pixel icon byte for byte. The source blob returned by GitHub matched the locally calculated Git SHA.

Release gate: a successful Vercel preview build and deployed icon/manifest checks must precede fast-forwarding the production branch. Deployment IDs and current release state are available in Vercel. A physical-phone home-screen check remains for Anthony; an existing saved shortcut may need to be removed and added again to adopt the new icon.

## Maintenance and rollback
Keep the versioned icon filenames when referring to this release. For a new design, replace the source intentionally, update its checksum, and change the filename version. Generated public images are ignored by Git and recreated during the build.

Rollback must revert only this icon commit, preserving any later unrelated work. Do not reset a shared branch or touch the database.
