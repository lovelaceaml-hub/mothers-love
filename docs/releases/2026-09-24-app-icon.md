# Open-hands-and-heart app icon

## Authorization and scope
On 2026-09-24 Anthony asked for the app icon to change to his picture of two open hands holding up a red heart. This replaces the butterfly-and-heart icon from docs/releases/2026-09-19-app-icon.md. Only the app symbol changes: browser tab icon, home-screen icon, Apple touch icon and the two install manifests. No screen, TV, recognition, database or sign-in change.

## Artwork
Anthony's picture was 96 by 96 pixels, too small for a sharp 512-pixel phone icon, so it was redrawn as vector artwork with the same shapes and colors: skin #F2C9A8, heart #E85A62, crease #D99B78. The generator places it on the app's cream background #FFF6DC, the same color as the theme and launch screen.

Repository source: assets/app-icon/open-hands-heart-v1.svg (checksum in scripts/generate-app-icons.mjs).
Reference: assets/app-icon/open-hands-heart-reference-96.png, Anthony's original picture, kept for comparison.

## Implementation
scripts/generate-app-icons.mjs now renders the SVG through sharp and writes the same seven sizes as before under the new versioned names public/icons/open-hands-heart-v1-*.png, plus public/apple-touch-icon.png and public/favicon.ico. src/app/layout.tsx, src/app/manifest.ts and public/display-manifest.webmanifest point at the new names. The butterfly AVIF source is removed; it stays in Git history and the archive/change/butterfly-heart-app-icon tag.

## After release
A phone that already saved the app to its home screen may keep the old icon until the shortcut is removed and added again.

## Rollback
Revert this one commit. Nothing else depends on it.
