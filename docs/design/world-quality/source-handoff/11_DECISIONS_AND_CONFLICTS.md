# Decisions, precedence, and contradictions to resolve before coding

The package deliberately contains older prototypes and handoffs so useful artwork/source is not lost. They are **not all simultaneously authoritative**. New root documents tell Codex how to use them without undoing later requirements.

## Precedence

The user's latest request sets the art scope: raise the quality of the **entire 3D world** toward the supplied pictures. Preserve the current repository's actual functional/privacy contracts and later corrections. Use the new root handoff documents to coordinate implementation. Use prototype READMEs as descriptions of those individual files, not global app rules. Historical plan wording never silently expands deployment authority.

The provided references have approved mood, material, composition and arrival direction. That does not certify that any earlier HTML or current PR has visually matched them. A successful script, a saved image, and user approval of a concept are three different forms of evidence.

## Stable design decisions

Keep the colorful, gentle campaign identity. Avoid toy-like repeated placeholder geometry, thick gold cages, unreadable drifting text, flat monochrome lighting, excessive bloom, or large cards covering a destination. Make petals, architecture and islands intentional; allow foreground, middle-distance and far silhouettes to create depth.

Keep the original sculpted heart's recognizable lobes, indentation, taper and volume. Four individually varying ribbon paths are a better reference than synchronized rigid hoops. Stage a clear entrance and reading interval for new recognitions; orbit only assigned expression symbols outside the reading face. Preserve fictional ambient neighbors but do not model them after actual recognition recipients.

The newer pictures show palace-like arches, flowering trees, pastel islands, silk, light and water. They do not authorize additional religious iconography, unprovided doctrinal text, crosses, saints, angels, crowns, or replacement of the campaign's canonical artwork.

## Do not infer new authorities

No automatic production promotion, cross-project deployment, paid asset purchase, external generation service, database modification, public field expansion, authentication change, or retention change follows from this handoff. Keep private real records out of prompts, logs, tests and saved captures. User-supplied concept text is a design prop, never seed data.

Do not invent that Codex ran another model, used Blender, performed a review, or measured a TV. Record actual capabilities and results. This plan contains proposed tasks; none is marked complete merely because it is described.
